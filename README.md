# Kora — site vitrine

Site vitrine pour Kora : création de sites sur-mesure et référencement local
pour artisans du bâtiment et boutiques indépendantes.

## Contenu

- `index.html` — page d'accueil (valeurs, avantages, méthode, avis, tarifs, FAQ)
- `contact.html` — page contact avec formulaire

Les deux fichiers sont autonomes : aucune dépendance, aucun build.
Ouvrez-les directement dans un navigateur, ou déposez-les sur n'importe
quel hébergement statique (GitHub Pages, Netlify, Vercel, OVH…).

## Mise en ligne sur GitHub Pages

1. Poussez ces fichiers à la racine de la branche `main`
2. Settings → Pages → Source : `main` / `/ (root)`
3. Le site est accessible sous quelques minutes
